# Vida Total

App de bienestar personal construida con [Next.js](https://nextjs.org) (App Router), TypeScript, TailwindCSS, y el design system "Liquid Glass".

Módulos: Home, Gym (calorías, agua, entrenamiento, kegel), Hábitos, Outfit, Paz Mental, Finanzas, Voz & Comunicación.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Build

```bash
npm run build
```
